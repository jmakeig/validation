# @jmakeig/validation

Data validation for the browser and Node.js.

## Development

Developed against Node.js 24 (see `.nvmrc`); supports Node.js 22+.

```sh
npm install
npm run test          # run tests once
npm run test:watch    # run tests in watch mode
npm run coverage      # run tests with coverage
npm run check         # type-check without emitting
npm run build         # build dist/ (ESM + type declarations)
npm run dev           # build in watch mode
npm run format        # format with Prettier
npm run format:check  # check formatting without writing
```

## Install

```sh
npm install @jmakeig/validation
```

This package ships as ESM only.
